**Nuvia 1.2.86 для Android 7.0 и новее, 64-разрядных устройств.**

В этой версии VPN работает через Xray. APK занимает 50 МБ. При загрузке подписки приложение переключается на резервный сервер, если основной недоступен.

Скачайте [APK 1.2.86](https://github.com/Nuvia-VPN/releases/releases/download/v1.2.86/Nuvia.apk) и установите его поверх прежней версии. Аккаунт и настройки сохранятся.

- **Free — 1 ГБ в сутки.** Начать можно без почты.
- **PRO — 500 ГБ в месяц.**
- Вход по почте и восстановление доступа.
- Ручной и автоматический выбор локации.
- Промокоды и поддержка внутри приложения.
